원격돌격 v4.7.5 - 계정 로그인 호환성 수정

중요: 이 업데이트는 기존 DB 파일이 서버 디스크나 백업에 남아 있을 때 호환·이전을 시도합니다. 이미 DB 파일이 완전히 삭제되어 어디에도 남아 있지 않다면, 새 코드만으로 계정/비밀번호/트로피를 재생성할 수 없습니다. 따라서 배포 전에 Render의 기존 Persistent Disk와 백업을 삭제하거나 교체하지 마세요.

수정 내용
- 이전 버전 계정 데이터의 사용자 이름을 정규화해 대소문자/유니코드 표기 차이로 계정을 못 찾는 문제를 줄였습니다.
- 이전 버전에서 평문 password 필드로 저장된 계정도 기존 비밀번호 확인 후 salt/passwordHash 방식으로 안전하게 이전합니다.
- DB 파일을 찾을 때 설정 경로, /data, 앱의 data 폴더, accounts.json 및 .bak 백업을 모두 검사합니다.
- 계정이 들어 있는 DB를 빈 DB보다 우선하고, 저장 전 기존 DB를 .bak으로 보존합니다.
- 탄약 한 발 재장전 시간은 그대로 유지합니다: 스파이더맨 2.0초, 망치보이 1.0초, 뱀파이어 1.3초, 뿌지직 1.2초, 메토 1.5초.

Render에서 확인할 사항
1. 기존 Persistent Disk가 그대로 연결되어 있는지 확인하고 삭제/초기화하지 마세요.
2. Mount Path는 /data, 환경 변수 DATA_DIR은 /data로 설정하세요.
3. Render 로그에서 '계정 DB 확인' 또는 '계정 DB 이전 완료' 메시지를 확인하세요.
4. 로그에 '계정 DB를 찾지 못했습니다'가 뜨면 추가 가입/저장 작업을 하기 전에 중단하고 Render 디스크/백업에서 기존 accounts.json을 찾아야 합니다.

파일 교체: index.html, server.js, package.json
실제 Render의 계정 DB에 접근할 수 없는 상태에서는 기존 계정 복구 여부를 여기서 보장할 수 없습니다.
